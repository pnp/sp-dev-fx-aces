# SharePoint Framework Adaptive Card Extension tutorials

Tutorials around SharePoint Framework Adaptive Card Extensions (ACEs) that demonstrate different capabilities of the framework. Each tutorial has its own README file that explains the setup instructions and the capabilities it demonstrates.

Tutorials are built step by step, so each one can include more than one project, and intermediate stages of a project in a `checkpoints` folder.

## Microsoft Learn module tutorials

Completed exercise code for the SharePoint Framework training modules on Microsoft Learn.
